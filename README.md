# Cipher

A local cryptography workbench for five classical ciphers, live analysis and language-aware shift scanning. Built with plain HTML, CSS and JavaScript.

**Live demo:** https://ayo-2010.github.io/cipher/

## Features

- Caesar, Vigenère, Atbash, Rail Fence and Playfair ciphers
- Encode and decode modes with live output as you type
- Key controls with validation and round-trip checks
- Four sample messages for quick experiments
- Caesar shift scanner ranked by English letter frequency
- Entropy, index of coincidence, letter count and unique-letter analysis
- Letter frequency chart built from the current output
- Method notes, formula and security notes for each cipher
- Copy, download or chain output back into the input
- Everything runs in the browser with no network requests
- Responsive layout down to 390px, reduced motion support and a global `[hidden]` rule

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
